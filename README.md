# 메인센터 가는 스타렉스 신청

주말 스타렉스 탑승 신청을 받고, 출발지별 신청자와 남은 자리를 확인하는 정적 웹앱입니다.

## 사용 방법

1. 이름과 출발지, 이용 구간을 선택합니다.
2. 함께 신청할 사람이 있으면 동행인을 추가합니다.
3. **신청하기**를 누르면 현재 브라우저에 내용이 저장됩니다.
4. **시간 수정**을 누르면 운행 요일과 출발 시간을 바꿀 수 있습니다.

입력한 내용은 서버로 전송되지 않고 각 사용자의 브라우저 `localStorage`에만 저장됩니다. 따라서 다른 기기나 다른 브라우저와 신청 현황이 공유되지는 않습니다.

## GitHub Pages

저장소의 루트(맨 위 폴더)를 GitHub Pages 배포 대상으로 선택하면 됩니다. `index.html`이 루트에 있고 모든 파일 경로는 상대 경로로 되어 있습니다.
